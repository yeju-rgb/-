How It Works

유지보수 방식

Update

공지·이벤트·상품 정보 같은 콘텐츠 교체와 디자인 미세 조정.
요청은 메신저 한 줄이면 충분합니다.

Fix

화면 깨짐, 링크 오류, 폼 미작동 같은 문제를 접수 즉시 확인하고 수정합니다.
원인과 조치 내용은 기록으로 남깁니다.

Improve

새 페이지 추가, 기능 보강, 속도·접근성 개선.
사용 데이터를 보고 먼저 개선안을 제안합니다.

Plan

진행 방식

월 단위 정기 유지보수와 건별 요청 두 가지로 진행합니다.
정기 유지보수는 매달 점검 항목을 정해 처리하고,
건별 요청은 범위와 일정을 먼저 안내한 뒤 작업합니다.

Promise

우리의 약속

"그건 안 돼요"보다 "이렇게 하면 돼요"를 먼저 말합니다.
작업 전후를 비교해 보여드리고,
직접 만든 사이트가 아니어도 같은 기준으로 돌봅니다.
